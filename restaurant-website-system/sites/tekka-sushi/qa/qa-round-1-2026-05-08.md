# Tekka Sushi — QA Round 1 — 2026-05-08

## Scope

First implementation QA after content, conversion, top-three improvements, concierge, pitch doc, and battle cards.

## Checks run

- `npm run typecheck` — passed
- `npm run build` — passed
- Headless mobile/desktop screenshots captured
- Playwright mobile DOM width check: 390px viewport, document scroll width 390px after menu mobile fix

## Findings

1. **Mobile menu item layout clipped/wrapped poorly at 390px.**
   - Initial mobile screenshot showed item descriptions appearing clipped near the right edge.
2. **Mobile sticky CTA label was too long.**
   - “Directions” could truncate on small screens.
3. **Qitchen home thumbnails created too much vertical delay before proof/actions on mobile.**
   - Cards were 28vh each, pushing conversion proof too far down.
4. **Concierge screenshot needed element-level evidence.**
   - Full viewport captured hero area before the concierge because Qitchen uses an internal scroll column.

## Fixes applied

1. Stacked mobile menu item rows, widened thumbnails to mobile card width, added break-word/overflow safety, and reduced mobile menu padding.
2. Changed sticky mobile “Directions” label to “Map.”
3. Reduced mobile thumbnail card height from 28vh to 18vh.
4. Captured the concierge element directly with Playwright and saved element screenshot evidence.
