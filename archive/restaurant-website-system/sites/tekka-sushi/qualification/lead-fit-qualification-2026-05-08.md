# Tekka Sushi — Lead-fit qualification — 2026-05-08

## Decision

**Build.** Tekka Sushi is a strong website-agency candidate because the live official menu page exposes obvious placeholder/template copy while public restaurant data shows a real, well-reviewed sushi/Japanese restaurant with menu depth and demand signals.

**Recommended template register:** **Qitchen** — modern sushi/Japanese, high-design menu presentation, precise visual rhythm, strong menu/order/directions conversion.

**Why-switch sentence:** If Tekka Sushi saw our redesign, the specific reason they would switch is that their owned website currently makes the menu look fake/template-filled, while a Qitchen-led site can make their real sushi, sashimi, ramen, and roll menu feel trustworthy and order-ready in seconds.

## 7 checks

1. **Visual reality:** Pass, with one caveat. Public profiles confirm real Japanese/sushi category, 39 photos on Restaurantji, and customer favorites dominated by sushi/sashimi/ramen. A browser/Google photo pass is still needed later before using room/interior language, but the restaurant category and menu reality match Qitchen rather than a warm family template.
2. **Menu pricing/register:** Pass. Beyond Menu exposes real sushi platter/menu depth, including Platter C at $93 with Fire Phoenix, caterpillar, sunny, sunset, California, Philadelphia, spicy tuna, spicy salmon, spicy kani, shrimp tempura, and Alaska rolls. Register reads modern sushi/order-forward rather than low-end quick-service.
3. **Review tone:** Pass. Restaurantji shows 4.8 from 170 ratings with favorites including Godzilla Roll, Crazy Tuna Roll, Spicy Crispy Tuna Roll, Yellowtail Hamachi, Fire Phoenix Roll, Regular Sashimi, Spicy Miso Ramen, and California Roll. Use this as public profile evidence only; verify Google review count/rating before using Google-specific sales copy.
4. **Current-site quality:** Fails strongly enough to justify a build. The live official `/menu` page returns placeholder/template categories and descriptions (`STARTERS`, `Drinks`, `Main`, `Dessert`; “Sed fermentum eros vitae eros”, “Feugiat maximus neque pharetra”, etc.) instead of real Tekka menu content. This is a concrete trust/conversion issue, not just “dated design.”
5. **Why-switch:** Pass. The switch reason is specific: owned-menu credibility is broken while real ordering/menu content exists offsite, creating a clear before/after pitch.
6. **Switching cost / inertia:** Moderate. The current order path uses Beyond Menu and a separate `tekkasushiil.com` ordering/discovery domain. The redesign should not ask them to rip out ordering; it should unify/clarify the official site, keep preferred order links, and make the real menu path trustworthy.
7. **Would-I-eat-here test:** Pass for the proposed hero posture if restrained: precise modern sushi, fresh rolls, order/directions clarity, and real menu depth. Do not oversell as omakase/luxury unless later photo/review evidence supports that.
